# 실사진 광고 제작 기록

방식: 내장 image_gen 도구, 각 안별 별도 호출. 입력은 사용자가 제공한 실제 박스와 파우치 사진이다. 원본 임시 경로와 개인 연락처는 저장소에 복사하지 않았다. 생성된 원본은 Codex generated_images에 남기고 최종 시안을 result에 복사했다.

공통 프롬프트: 실제 크림색 손잡이 박스·납작한 밀봉 파우치, 회색 사과 패턴·초록 아치·노랑/빨강 얼음골·사과하나 글씨·사과 그림을 유지. 스파우트·새 브랜드·허위 인증·할인·건강 주장을 추가하지 않음. 고급 한국어 상업 사진 포스터, 정사각형, 자연스러운 조명·여백, 실제 네이버 화면을 모방하지 않음.

1. 아이보리·초록 스튜디오, 박스+파우치. 정확한 큰 문구: 청송사과즙 / 한 박스 구성을 한눈에 / 120ml × 50포 / 삼형제농원.
2. 아침 식탁·가방 가장자리, 실제 박스·파우치. 정확한 큰 문구: 청송사과즙 / 한 포씩, 간편하게 / 120ml × 50포 / 삼형제농원.
3. 세이지 초록 스튜디오·받침대, 실제 박스·파우치. 정확한 큰 문구: 청송사과즙 / 총 6L, 한 박스에 / 120ml × 50포 / 삼형제농원.

요약 인포그래픽 프롬프트: 아이보리·초록·빨강의 세로 한국어 설명자료. 제목 청송사과즙, 이렇게 판매를 늘립니다. ①86,025노출·348클릭·26,664원·322행·광고귀속전환10건(순주문 아님) ②비교8개중앙값30,000원 대 우리39,900원(+33%, 품질동등비교아님) ③10/21–27 A44노출0클릭OFF/B0노출0클릭ON, 아직승자없음·무작위A/B아님 ④출고정보→청송사과키워드→문구/사진순차비교→순판매량/이익. 수치를 그대로 표현하고 성공효과를 만들어내지 않음.

검수: 큰 문구·단위·필수청송사과·실제 포장 형태 확인. 작은 포장 글자는 생성 과정에서 변형될 수 있어 최종 집행 전 원본 대비 교정 필요. 이미지들은 실제 출고·제조상태를 증명하지 않으며 원본 사진 자체를 그대로 합성한 정밀 납품본이 아닌 AI 보정 시안이다. 대표이미지 규정 적합성을 보장하지 않는다.
