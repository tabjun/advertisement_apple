## 바로 볼 파일

- `full_page.png`: 전체 상세페이지, 860×7100px.
- `index.html`: 편집 가능한 미리보기. 같은 폴더의 사진 파일과 함께 열기.
- `01_product.png`: 제품·가격·구성.
- `02_sip.png`: 파우치를 뜯어 바로 마시는 장면.
- `03_how_to.png`: 산뜻한 음용 안내 3컷.
- `04_process.png`: 세척 → 착즙 → 충전·밀봉 → 박스 포장 설명도.
- `05_box.png`: 120ml×50포, 총 6L 구성.
- `contact_sheet.png`: 개별 이미지 5장 한눈에 보기.

전체 시안에는 위 5장 외에 인증서 자리·제품 표시사항·배송 안내가 포함되어 있습니다. PNG는 원본 사진과 글자를 조합한 출력이며 HTML과 간격은 일부 다릅니다. 상품 등록·광고 게재는 하지 않았습니다.

## 친구분께 받을 자료

- 공식 인증서 전체 사진: 인증명, 사업장명, 인증번호, 유효기간이 읽히게. **HACCP 여부는 아직 미확인**입니다.
- 실제 제조 과정 사진: 세척·착즙·충전·포장. 공정 순서와 조건도 제조원에 확인합니다.
- 현재 출고 파우치 뒷면 표시사항과 제조일·소비기한 각인.
- 실제 판매 박스 사진, 출고 마감·제주/도서 추가 배송비·교환 조건.

제품·박스·음용 모델 사진은 AI 연출이며 실제 고객·실제 공장·최종 포장 증빙이 아닙니다. 라벨의 작은 글자는 실물과 동일성을 보장하지 않습니다. 실제 증빙을 받으면 해당 영역만 교체합니다. 인증 마크와 미확인 검사 결과는 넣지 않았습니다.

`manifest.json`은 제작 범위와 검증 상태, `generation_prompts.json`은 새 이미지 생성 조건을 기록합니다. 실제 동작 영상은 이번 패키지에 포함되지 않습니다.
